# Source register: every public data source the team uses

The brief asks, for every outside source: **(1) publisher and exact series, (2) geographic grain, (3) time grain, (4) why we chose it over an alternative.** This page answers those four for each source, plus the vintage, publication lag and link.

- Join key everywhere: 5-digit county FIPS `fips`, read as **text**.
- Competition data (food shelf `org_FSStats`, `Organization`, `Incoming Call`, `marketbucksUsage`, MDE school meals) is not listed; it's provided by the organizers.
- **August 2026 rule:** no source below contains data for August 2026 or later in the files we use. The SNAP dashboard file downloaded after the cutoff (`snap-dashboard-data-through-september-2026.xlsx`) is **not** used by any of these tables.
- Last updated: 2026-10-12 (MN DEED cost of living, USDA SNAP retailers and MN WIC added by `notebooks/06c_extra_factors.ipynb`, section B3; ACS via the Census API by `06b`, section B2; earlier: `06a`).

## B2. ACS 5-year via the Census API, added by `06b_acs_factors.ipynb`

All: US Census Bureau, American Community Survey 5-year detailed tables, `api.census.gov/data/{year}/acs/acs5` (key read from `Data/local/census_api_key.txt`, git-ignored, never saved). **(2) Geo grain:** county (all 87 MN counties). **(3) Time grain:** 5-year rolling window, labelled by end year: 2018–22, 2019–23, 2020–24 (the 2020–24 vintage was released December 2025). **Publication lag:** ~1 year (Dec of the following year; 2020–24 released Dec 2025). Every share has a 90% MOE column (Census formulas); `acs_n_high_cv` counts unreliable shares per row. Raw JSON: `Data/external/public_factors/raw/census_acs/`. Output: new columns in `county_factors_2022_2024.csv` (existing columns unchanged).

## C. Looked at but not used

| Source | Why not |
|---|---|
| MDE school meal claim files (`Data/MDE School Meal Data/`) | Rows are sponsor/site IDs with no county or address field, so they can't be put on counties without an outside site-to-county list. Also, Minnesota has had **universal free school meals since 2023-24**, so free/reduced claim counts no longer reflect income eligibility. CHR's `chr_pct_children_frl_eligible` (B8) is used instead. See `data_wishlist.md`. |
| BLS LAUS flat files (`laucntyYY.xlsx`) | HTTP 403 for scripts; the same numbers came from the API (B2). |
| ACS B22001 / B22002 (SNAP receipt by presence of seniors / children) | Not pulled yet (key now available, see B2); lower priority because the overall SNAP gap (C1) explained nothing. |
| ACS B11007 (households with a 65+ member living alone) | B09020 (C5) used instead: it counts people 65+, which matches "seniors served". |
| CBP supercenters (`452311`) | Published for only 16 of 87 counties (< 3 rule). |
| CHR `Living Wage` | Blank for every MN county in the 2025 file. |
